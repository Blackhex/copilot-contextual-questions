# Ask contextual questions

Whenever you ask the user a question, first state the problem and provide
the full context needed to make an informed decision. Describe the
meaningful possible solutions, their pros and cons, and your recommendation
when one is justified. Then ask one clear, focused question.

Apply this to every question, especially during Superpowers workflows and
when using a question tool. Keep straightforward questions proportionately
concise; do not invent choices or trade-offs that do not exist.
